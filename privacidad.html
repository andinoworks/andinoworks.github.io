Política de privacidad de auto shorts

Última actualización: 3 de noviembre de 2026.

Qué es esta aplicación

auto shorts es una herramienta de uso personal, usada únicamente por su autor, para subir videos a su propio canal de YouTube mediante la API de datos de YouTube.

Datos a los que accede

La aplicación usa el permiso de Google para subir videos a la cuenta que la autoriza, con el token de acceso que Google entrega al hacerlo. No solicita ni recopila datos de otras personas.

Cómo se usan y guardan

El token se guarda solo en la computadora del autor y se usa únicamente para publicar sus videos y sus miniaturas. La aplicación no tiene servidores propios.

Con quién se comparten

Estos datos no se venden ni se comparten con terceros. Los videos y sus textos se envían a YouTube para publicarlos.

Servicios de Google

Esta aplicación usa los servicios de la API de YouTube. Al usarlos se aplican las Condiciones del servicio de YouTube y la Política de privacidad de Google.

Cómo revocar el acceso

El acceso se puede revocar en cualquier momento desde los permisos de la cuenta de Google. Para pedir la eliminación de datos, escribí al contacto de abajo.
